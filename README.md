# ⚔️ SoulBonker 3D : Megabonk x Souls-Like Rogue-Lite Arena

Un jeu d'action rogue-lite 3D ultra-nerveux et dynamique mêlant la physique loufoque et les impacts percutants de **Megabonk** avec l'exigence technique d'un **Souls-Like** (gestion d'endurance, esquives parfaites avec Bullet Time, boss d'arène).

Conçu spécialement pour **jouer confortablement sur PC Portable / Mac en amphi sans souris**, avec consommation minimale de batterie (< 3W), ventilateurs totalement silencieux et **100% hors-ligne**.

---

## 💻 Configuration Spéciale Ordinateur Portable (Deux Mains sur le Clavier)

Plus besoin de galérer avec le trackpad ! Le jeu intègre une **Visée Automatique Intelligente (Smart Auto-Aim)** : vos attaques ciblent automatiquement le monstre le plus menaçant ou le plus proche dans la direction de votre mouvement.

| Main | Touche | Action |
| :--- | :--- | :--- |
| **Main Gauche** | **`Z` `Q` `S` `D`** ou **`W` `A` `S` `D`** | Se déplacer dans l'arène |
| **Main Droite** | **`J`** | **Attaque Légère** (Combo 3 coups : Balayage $\to$ Smash $\to$ Tourbillon) |
| **Main Droite** | **`K`** | **Attaque Lourde / Megabonk** (Maintenir pour charger) |
| **Main Droite** | **`L`** ou **`Espace`** | **Roulade / Esquive Parfaite** (Bullet Time + Endurance 100%) |
| **Main Droite** | **`I`** ou **`R`** | Verrouiller une cible (**Lock-On**) |
| **Choix de Cartes** | **`[1] / J`**, **`[2] / K`**, **`[3] / L`** | Sélectionner une amélioration sans quitter les mains du clavier |
| **Navigation** | **`Espace` / `Entrée` / `J`** | Lancer la partie / Recommencer après Game Over |
| **Pause** | **`P`** ou **`Échap`** | Mettre en pause discrètement |

*(Note : le jeu reste également compatible manettes PS5/Xbox/Switch et souris/trackpad si vous préférez !)*

## ⚡ Mécaniques Clés

### 1. 🛡️ L'Esquive Parfaite (Perfect Dodge) & Bullet Time
- Esquivez avec `L` ou `Espace` **juste avant** qu'une attaque ennemie ne vous touche.
- **Récompenses immédiates** :
  1. **Bullet Time** (ralenti temporel spectaculaire de 1.4s).
  2. Recharge **instantanée à 100%** de votre jauge d'Endurance.
  3. Activation du buff **Mega Bonk** (+120% dégâts sur votre prochain coup avec coup critique garanti).

### 2. 🟢 Gestion de l'Endurance (Stamina)
- Frapper, rouler et charger des attaques consomme de l'endurance.
- Si la barre est vide, vous passez en état d'**Épuisement** (vitesse ralentie, roulade bloquée pendant 1s).

### 3. 💥 Physique Megabonk & Ring-Outs
- **Slam contre les piliers** : projeter un monstre contre un pilier lui inflige de lourds dégâts bonus.
- **Ring-Out** : éjectez les monstres par-dessus les rebords de l'arène dans le vide infini !
- **Renvoi de Projectiles** : donnez un coup de batte sur les orbes des mages pour les renvoyer en pleine tête des ennemis !

### 4. 🃏 Deck d'Améliorations Rogue-Lite
À chaque fin de vague, choisissez 1 carte parmi 3 (sélectionnable directement avec `J`, `K` ou `L`) :
- ⚡ **Éclair en Chaîne** (*Épique*) : les coups frappent jusqu'à 3 ennemis avec des arcs électriques.
- 🔨 **Masse Colossale** (*Rare*) : taille et portée d'arme +40%, dégâts +25%.
- ⏱️ **Adrénaline Suprême** (*Légendaire*) : endurance infinie et vitesse x1.5 pendant les esquives parfaites.
- 🩸 **Bonk Vampirique** (*Rare*) : 25% de chance de restaurer +8 PV sur chaque coup.
- 👻 **Dash Fantôme** (*Épique*) : la roulade tranche tous les ennemis traversés.
- 💥 **Propulsion Megabonk** (*Rare*) : +60% de knockback.
- ❤️ **Vitalité de Titan** (*Commune*) : +40 PV Max et soin complet.
